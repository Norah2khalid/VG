# VISIONGUARD (فيجن قارد)
منصة تفتيش صناعي عربية (RTL) تعمل بوضع المحاكاة. جميع البيانات والتحليلات والتليمتري **تجريبية**.

## التشغيل
```
npm install
npm run dev      # التطوير
npm run build    # فحص TypeScript + بناء الإنتاج
```
## البنية
`src/types` النماذج · `src/data/demoData.ts` البيانات المركزية · `src/store.tsx` الحالة (الدور، المهام، القرارات) · `src/services/ai` طبقة الذكاء الاصطناعي · `src/pages` الصفحات الأربع · `src/layouts` الهيكل · `src/components` المكونات.

## وضع المحاكاة والأدوار
تبديل الدور (المدير/المفتش/جامع التقارير) للعرض فقط وليس أمناً حقيقياً؛ التحقق الفعلي يجب أن يتم في الخادم.

## ربط خادم مستقبلاً
استبدل قراءات `demoData.ts` داخل `store.tsx` باستدعاءات API (`VITE_API_BASE_URL`) مع الحفاظ على الأنواع في `types`.

## ربط ذكاء اصطناعي حقيقي
نفّذ واجهة `AIService` في `services/ai/types.ts` (رؤية حاسوبية/LLM/API)، سجّلها في `aiService.ts`، واضبط `VITE_AI_PROVIDER`. المفاتيح السرية تبقى في الخادم، لا في الواجهة. يجب إبقاء المراجعة البشرية لكل نتيجة.

## ربط درون/أجهزة
`DEVICES` في البيانات بحالات `LIVE|IMPORTED|SIMULATION|UNAVAILABLE`. أضف خدمة `services/devices` تقرأ من بوابة (MQTT/WebSocket/REST) عبر الخادم وغيّر الحالة إلى `LIVE` فقط عند اتصال فعلي.
